# backend skip list -- tests SKIPPED under a backend for a PERMANENT reason, i.e.
# one that no amount of porting work will change. Two kinds qualify:
#
#   (a) the test exercises NO backend-relevant code and depends on a flaky external
#       service (e.g. Orbit.from_name's SIMBAD lookup), so running it under a forced
#       backend only risks flaking the deterministic all-backend gate for ~zero
#       coverage; or
#   (b) the test belongs to a family that is out of scope for the backend goal and
#       stays _reject_backend-guarded (actionAngleVerticalInverse), so it fails by
#       design and always will.
#
# conftest.py marks each matching nodeid pytest.mark.skip with a
# "backend-skip: not backend-meaningful ..." reason, in BOTH normal and regen mode.
#
# This is DISTINCT from backend_slow_skip.txt (slow-but-meaningful, deferred pending
# the backend port's vectorization -- a burndown that shrinks to zero) and from
# backend_xfail.txt (known-failing, to be fixed). These are a PERMANENT exclusion,
# NOT pending work, so they are not part of any burndown. numpy still runs them.
# A nodeid here must NOT also be in backend_slow_skip.txt or backend_xfail.txt.
#
# format: <backend> <nodeid>   (same as the other ledger files)
#
