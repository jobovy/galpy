# backend skip list -- tests SKIPPED under a backend for a PERMANENT reason, i.e.
# one that no amount of porting work will change. Two kinds qualify:
#
#   (a) the test belongs to a family that is out of scope for the backend goal and
#       stays _reject_backend-guarded (actionAngleTorus, via streamdf's useTM), so
#       it fails by design and always will; or
#   (b) ONE potential in a per-potential walk whose cost under eager jax is a
#       floor no port removes -- the work is a Python-stepped loop of correct,
#       already-migrated backend calls, so the only thing that would fix it is
#       jit, which galpy deliberately does not do internally. This category only
#       became expressible once the walks ran one case per potential (gh#1467):
#       before that, deferring the potential meant deferring the whole walk.
#
# conftest.py marks each matching nodeid pytest.mark.skip with a
# "backend-skip: not backend-meaningful ..." reason, in BOTH normal and regen mode.
#
# This is DISTINCT from backend_slow_skip.txt (slow-but-meaningful, deferred pending
# the backend port's vectorization -- a burndown that shrinks to zero) and from
# backend_xfail.txt (known-failing, to be fixed). These are a PERMANENT exclusion,
# NOT pending work, so they are not part of any burndown. numpy still runs them.
# A nodeid here must NOT also be in backend_slow_skip.txt or backend_xfail.txt.
#
# format: <backend> <nodeid>   (same as the other ledger files)
#
# --- streamdf's useTM tests reach actionAngleTorus ---
# "NotImplementedError: actionAngleTorus wraps the external Torus C++ library
# and is not jax-..." -- the same standing decision that excludes
# test_actionAngleTorus from the all-backend suite: an external C++ wrapper is
# out of scope for the backend goal, so this is a PERMANENT exclusion, not a
# burndown item. Surfaced by the slow-skip inheritance split; the eager `jax`
# whole-file slow-skip had been hiding them.
#
# The guard is backend-shaped, not trace-shaped, and torch confirms it: a whole
# -file `--backend torch` run fails these 4 and only these 4, identically with
# and without the streamdf out-of-place fix. So torch is entered too, and the
# permanent-skip list inherits it for torch-jit.
#
# CI never sees any of this: these tests need the external Torus C++ library,
# which is built on the dev box but not in CI, so there they skip before ever
# reaching the backend guard. Local-only exposure -- which is exactly why it
# needs a list entry rather than a CI observation.
#
# Plain `jax` is deliberately NOT entered: the eager whole-file slow-skip means
# it has never been measured, and claiming it would assert past the evidence.
